# Power BI Sales Dashboard

Sales analysis dashboard created in Microsoft Power BI.

## Project Overview

The dashboard was created to analyze weekly sales performance and product results.

It allows users to quickly identify:
- changes in weekly revenue,
- best-selling products,
- products generating the highest revenue,
- sales trends over time.

## Dashboard Preview

The report includes:

- Weekly revenue trend
- Week-over-week revenue change
- Product ranking by number of units sold
- Product ranking by revenue

## Key Insights

The dashboard makes it possible to compare product performance and quickly identify the products that contribute most to sales and revenue.
